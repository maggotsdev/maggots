# Disclosure

Read this before you buy anything.

**What MAGGOTS is.** A web page that runs a simulation of a fruit fly larva's brain, built from a public scientific dataset, and reacts to trades of another token on Robinhood Chain. A token with the same name, launched on a public launchpad. A script that uses that token's creator fees to buy a second token and send it to holders.

**What it is not.** Not an investment. Not a company. Not affiliated with the authors of the connectome, with Alphabet, Robinhood, Pons, Uniswap, or the flybrain project. It is a maggot.

**The brain is a caricature.** The public table has no transmitter signs, so every connection excites. We hold the network stable with global inhibition and spike-frequency adaptation that a real larva does not have in that form. The scatter is not soma positions. The crawl rhythm is a constant. The five crawl behaviours are our split of the descending neurons. The feeding neurons and the senses use the paper's labels. The lobe split for learning is ours. All of this is on the page and in the paper.

**The trade map is a rule set, not intelligence.** Sells of the fly become smell, buys become light, big sells add dopamine. No language model, no strategy, no prediction. Given the same brain state and the same trades, the same reaction comes out.

**The gut is a script on one machine.** It holds one wallet's key. It claims fees, swaps on Uniswap v4, snapshots holders from Transfer logs, and sends tokens in a loop. It can fail mid-epoch. It can be late. If the machine is off, nothing happens that day. Every transaction hash goes in the ledger on the page.

**Holders are paid in FLYBRAIN, a memecoin.** Its value can go to zero. The gut buys it at market, in slices timed by the brain, which is not a good trader because it is not a trader.

**The brood counts tabs, not people.** Anyone can open ten tabs and be ten maggots.

**Numbers.** The paper reports 3,016 neurons and 548,000 synapses. The public processed table we load has 3,013 neurons and 353,859 counted synapses on 111,243 connections. We show what we load.

**The person behind it** is one person with a laptop. There is no team page because there is no team.
